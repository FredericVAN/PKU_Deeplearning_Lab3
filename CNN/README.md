# 石卓凡-CNN的实现

数据预处理：

1. **数据加载与格式转换**：

   - 通过 `load_data`函数从 `train_32x32.mat`和 `test_32x32.mat`文件中加载SVHN（Street View House Numbers）数据集。
   - 将数据从原始格式 `(32, 32, 3, samples_count)`转换为更适合处理的格式 `(samples_count, 32, 32, 3)`。
   - 训练集包含73,257张图像，测试集包含26,032张图像，总共99,289张图像。
2. **数据预处理步骤**：

   - 将训练集的一部分拆分为Eval数据集
   - 将标签中的10转换为0（因为SVHN数据集中数字"0"被标记为10）
   - 将彩色图像转换为灰度图像以简化计算
   - 对数据进行标准化处理


实现了一个卷积神经网络(CNN)模型来处理SVHN(Street View House Numbers)数据集。SVHN是一个包含房屋门牌号码图像的数据集，主要功能如下：

1. 数据处理：将32x32像素的灰度图像加载并预处理为神经网络的输入格式。
2. CNN模型结构：实现了一个基本的CNN架构，包含以下层次顺序：

   - 输入层
   - 卷积层 + ReLU激活函数
   - 卷积层 + ReLU激活函数
   - 池化层
   - Dropout层(防止过拟合)
   - 全连接层 + ReLU激活函数
   - 输出层(全连接层)
3. 训练过程：

   - 使用小批量梯度下降法训练模型
   - 设置丢弃率(dropout)防止过拟合
   - 在训练过程中计算并显示每批次的损失和准确率
   - 同时计算验证集上的准确率
4. 模型评估：

   - 在测试集上评估模型性能
   - 计算总体准确率
   - 创建混淆矩阵以可视化不同数字类别的分类准确率
5. 结果可视化：

   - 显示混淆矩阵热图
   - 展示被错误分类的图像样本

这个项目的目标是训练一个能够从街景图像中识别数字的神经网络模型，可以应用于地址识别、车牌识别等场景。
